# Data Sources (Milestone 2)

## 1. Nova Scotia Provincial Highway Traffic Volumes
Description: Annual average daily traffic (AADT) counts across provincial highway segments.
Use in project: Measures vehicle flow intensity and long-term trends in traffic volumes, serving as a proxy for congestion pressure.
Source: https://data.novascotia.ca/Roads-Driving-and-Transport/Traffic-Volumes-Provincial-Highway-System/8524-ec3n/about_data

## 2. Halifax Regional Municipality Open Data Catalogue
Description: Municipal datasets including transportation, land use, and infrastructure indicators.
Use in project: Identifying relevant local infrastructure context and possible spatial patterns.
Source: https://data-hrm.hub.arcgis.com/datasets/open-data-catalogue-1/explore

## 3. Halifax Regional Municipality Open Data Downloads Portal
Description: Downloadable municipal datasets supporting transportation planning and mobility analysis.
Use in project: Supporting local infrastructure analysis and contextual interpretation.
Source: https://data-hrm.hub.arcgis.com/pages/open-data-downloads
